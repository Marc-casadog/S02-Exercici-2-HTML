Horario de asignaturas

Asignaturas:

  • Programación: permite aprender a crear programas y resolver problemas mediante código.
  • Bases de datos: enseña a organizar, consultar y gestionar información.
  • Sistemas informáticos: estudia los sistemas operativos, los equipos y las redes.
  • Lenguajes de marcas: permite estructurar documentos y contenido web con HTML y XML.
  • Entornos de desarrollo: enseña a utilizar herramientas para programar y comprobar el código.

Siglas y nombres completos

  • PR — Programación
  • BD — Bases de datos
  • SI — Sistemas informáticos
  • LM — Lenguajes de marcas
  • IPO — Itinerario para la ocupabilidad
